# M1 — журнал калибровки сегментации

Дата: 2026-11-25. Этот документ фиксирует результаты первой проверки M1, чтобы не повторять подбор порогов без новых данных или ручной разметки.

## Проверенная запись

- Ручной подсчёт: **8 forehand-замахов**.
- Локальный экспорт: `data/landmarks_1795552262931.csv` и соответствующий `*.metadata.json`.
- Параметры записи: 1280×720, поворот 90°, MediaPipe Pose Landmarker Lite, правая ведущая рука, боковой ракурс.
- В CSV: 657 кадров данных и заголовок.

## Наблюдения

- Скорость считается в world-координатах ведущего запястья относительно середины таза, с нормировкой на длину торса.
- На сырых данных есть большие пики и близко расположенные всплески; одна только склейка по времени не даёт устойчивого результата.
- Pose Landmarker местами путает ноги. Поэтому метрики коленей на этой записи нельзя трактовать как надёжные без проверки доли валидных кадров и визуального просмотра.
- Отладочный просмотр синхронно меняет кадр и скелет. Для быстрого перемещения используются компактные предпросмотры кадров, созданные во время анализа.

## Решение

Не продолжать ручной подбор порогов по числу повторов. Следующий шаг M1 — добавить ручную разметку пиков замахов в покадровом просмотре и сравнение с автоматическими пиками. Ручные 8 меток станут ground truth для этой записи.

После этого нужно:

1. показывать график world-скорости запястья с автоматическими и ручными пиками;
2. выбирать параметры по совпадению с ручной разметкой, а не по одному итоговому счётчику;
3. показывать долю валидных кадров для левой и правой ноги и скрывать ненадёжные коленные метрики;
4. проверить параметры ещё как минимум на одном ролике с ручным подсчётом.

M1 нельзя закрывать до выполнения этих пунктов и проверки на реальном устройстве.
